Kebijakan Privasi

Anjai hanya meminta izin mengunggah video ke YouTube (scope youtube.upload) untuk channel milik pemilik alat ini.

  • Token akses disimpan secara lokal di komputer pemilik dan tidak dibagikan ke pihak mana pun.
  • Anjai tidak membaca, menyimpan, atau menjual data pribadi, kontak, atau video orang lain.
  • Akses dapat dicabut kapan saja di Pengaturan Akun Google.

Penggunaan data yang diterima dari Google API mematuhi Kebijakan Data Pengguna Layanan API Google, termasuk persyaratan Penggunaan Terbatas.
